# SaddleBrooke Strength website

This repository contains the complete source code and production assets for the SaddleBrooke Strength website created in ChatGPT Sites.

## Projects

- `sites/home` — Main SaddleBrooke Strength homepage
- `sites/personal-training` — One-on-one personal training page
- `sites/golf-fitness` — Golf fitness program page
- `sites/group-classes` — Cardio Kickboxing and Ageless Jiu-Jitsu pages
- `sites/inbody-testing` — InBody 380 and grip-strength testing page

Each project is preserved as an independent deployable app, matching the current published website structure.

## Local development

Open the project you want to run, then:

```bash
npm ci
npm run dev
```

To create a production build:

```bash
npm run build
```

Generated dependencies, build output, and local runtime caches are intentionally excluded.
